# Lab 02 report

Use [the PDF](lab_02_report.pdf) for reading and [the Word version](lab_02_report.docx) for editing. Both contain the reviewed seven-page report. The [LaTeX source](source/main.tex) and source figures follow the Lab I style.

From the repository root, `conda activate intr5100` and run `PYTHONDONTWRITEBYTECODE=1 python src/build_report.py`. This rebuilds both editable formats and compiles the PDF, using the saved records without refitting or rerunning scientific simulations. The current build verification is in `../review/report_build_checks.json`.

`archive/` contains the original October 20 draft, its builder and template evidence for provenance. Those are historical sources, not additional current report versions.
