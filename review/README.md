# Verification records

- `review_notes.md`: report findings and the fixed-results constraint.
- `report_revision_checks.json`: historical October 22 report-review snapshot, before repository reorganization.
- `organization_manifest.json`: old-to-new file paths.
- `report_build_checks.json`: current report builder checks and protected file hashes.
- `dropin_checks.json`: current six-candidate GUI compatibility diagnostics, using synthetic telemetry only.
- `publication_checks.json`: publication-time preservation, test and portability checks.

Historical snapshots retain their original paths and timestamps. Use the organization manifest to resolve renamed paths; they are not instructions to restore an older folder layout. No physical experiments, fitted parameters or recorded numerical outcomes were replaced by these checks.
